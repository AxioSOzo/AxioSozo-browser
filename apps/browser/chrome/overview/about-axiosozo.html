Needs attention

    Contexts

    A context is a Zen workspace with a type. Each workspace keeps its own container, so sign-ins stay separate.

    Projects

    A project is a local folder with confirmed names, addresses and services. Detection reads only a fixed list of configuration files and never runs anything.

      Site rules

      A site rule is your own instruction for a set of sites, with limits the browser enforces locally. You can always continue past a rule.

        Screen time

        Foreground time per site, per context, per day. Kept on this machine for 90 days and never uploaded. Private windows are not recorded.

        Metadata for deleted workspaces

        These workspaces no longer exist. Their AxioSozo settings are kept but never reused. Remove them if you do not need them.
