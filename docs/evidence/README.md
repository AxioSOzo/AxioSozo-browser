# Development evidence

The raw logs, screenshots and machine-generated results under this directory
were collected on the maintainer's macOS development machine. They remain local
because they can contain machine-specific paths, session details and diagnostic
output. The public source repository includes the code and status summaries, but
does not claim that a public reader can independently reproduce the recorded
native GUI observations from those summaries alone. References to specific
evidence files elsewhere in the documentation name local files omitted from the
public repository.

Run the documented checks on your own supported environment and retain your own
evidence before asserting E1/E2 or browser readiness. The current status is
[PARTIAL_ENGINE_BLOCKED](../SETUP_STATUS.md).
